## SDK additions

| Class | Responsibility |
|-------|----------------|
| `ContactRef` | record `(UUID serverId, String userId)` |
| `ChatRef` | record `(UUID serverId, String chatId)` |
| `MultiServerWsHub` | map serverId → `WsSession`; connect/disconnect per server |
| `PlatformSecureStorage` | Win DPAPI / macOS Keychain / Linux file+chmod |
| `ProfileManager` | list/switch/create profiles; wipe memory on switch |

### Server registry rules

- CRUD UI: add/edit/remove server
- Health probe before save: `GET /api/v1/health`
- `paused: true` → не держать WS, grey badge в UI

### Contact identity

- Один `userId` на двух серверах = **два контакта**
- Display: `{serverDisplayName} · {userDisplayName}`
- Ключ кэша: `serverId + ":" + userId`
