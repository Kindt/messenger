## SDK — классы (минимум)

| Class | Responsibility |
|-------|----------------|
| `DesktopPaths` | `%APPDATA%/KorusMessenger`, Downloads attachments root |
| `ProfileStore` | load/save `profile.json` per `contracts/local-profile.schema.json` |
| `ServerRegistry` | один сервер в W0; `contracts/server-registry.schema.json` |
| `SecureTokenStore` | interface + `WindowsSecureTokenStore` stub (file fallback dev) |
| `KorusApiClient` | OkHttp: health, capabilities, login |
| `AuthSession` | access/refresh token + serverId |

### API (QEMU default)

| Call | Method | Path |
|------|--------|------|
| Health | GET | `/api/v1/health` |
| Capabilities | GET | `/api/v1/platform/capabilities` |
| Login | POST | `/api/v1/auth/login` body `{"username","password"}` |

Base URL из registry: `http://127.0.0.1:18080` (без trailing slash).

## JavaFX — экраны W0

| FXML | Controller | Flow |
|------|------------|------|
| `profile-picker.fxml` | `ProfilePickerController` | первый запуск → создать профиль |
| `login.fxml` | `LoginController` | URL сервера (prefill), user/pass, login |
| `shell.fxml` | `ShellController` | label сервера + capabilities summary + logout |

`DesktopApplication`: load profile → if no servers show login → on success show shell.
