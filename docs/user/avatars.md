# Аватары в Korus Messenger

## Как сменить аватар

1. Откройте **Настройки** (иконка шестерёнки).
2. В разделе профиля нажмите **Сменить аватар** и выберите изображение (JPEG, PNG, WebP, GIF до 2 МБ).
3. Чтобы убрать фото, нажмите **Удалить аватар** — снова отобразятся инициалы.

Для группового чата: меню чата → редактирование (только владелец или администратор).

## Кто видит аватар

- **Пользователь:** участники той же организации (если не включена политика «только контакты»).
- **Группа / канал:** участники чата.
- **P2P:** в списке чатов показывается аватар собеседника.

Аватар **не шифруется E2EE** — это отдельный org-visible ресурс, не содержимое сообщений.

## Технические ограничения

- Форматы: JPEG, PNG, WebP, GIF (анимация сохраняется как статичный кадр).
- SVG не поддерживается.
- Максимальный размер загрузки: 2 МБ.

## Политика организации

Администратор может запретить загрузку (`disabled`) или разрешить только импорт из LDAP/Keycloak (`ldap_only`). При запрете кнопка смены аватара недоступна.

## Скрытие аватара

В настройках конфиденциальности можно скрыть свой аватар от других пользователей — они увидят инициалы.
