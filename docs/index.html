§0.1 Блокеры production

  • Нет промышленного stage/prod стенда (планируется с сентября 2026) — formal load test и ops sign-off отложены
  • Prod HTTPS/TLS: поставка в Ansible есть, боевые сертификаты и vault — на контуре заказчика
  • E2EE: инженерная приёмка пройдена; требуется sign-off ИБ перед массовым включением
  • WebRTC: mesh из чата готов; TURN в prod-контуре — настройка IT заказчика
  • Web Push: UI/worker готовы; боевые VAPID и проверка на стенде — ops
  • SSO/LDAP: скрипты и runbook есть; подключение live IdP/AD — ops
  • Мобильные клиенты iOS/Android — вне текущей поставки
  • Live-streaming (§28) — в roadmap, не реализован

↑ см. статус прототипа

Зачем мессенджер

↑ см. статус прототипа

Корпоративный мессенджер — как чат в телефоне, но для работы: переписка, файлы, звонки.

Данные остаются у вашей компании. Администратор видит, кто что отправил — для порядка и аудита.

Сейчас это рабочий прототип: основные сценарии работают на тестовом стенде.

Альтернативы

Есть облачные сервисы и решения «у себя в офисе». Korus — для организаций, где важны контроль данных и экспорт.

Мобильные приложения из магазина — пока не в поставке; браузер и установка «как приложение» — да.

Удобство

Удобство: поиск по переписке, файлы в чате, звонок одной кнопкой.

Частично: уведомления на телефон — нужна настройка IT; усиленное шифрование — после согласования с безопасностью.
