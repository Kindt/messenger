Что мешает production

  • Нет промышленного stage/prod стенда (планируется с сентября 2026) — formal load test и ops sign-off отложены
  • Prod HTTPS/TLS: поставка в Ansible есть, боевые сертификаты и vault — на контуре заказчика
  • E2EE: инженерная приёмка пройдена; требуется sign-off ИБ перед массовым включением
  • WebRTC: mesh и LiveKit SFU из чата готовы; TURN в prod-контуре — настройка IT заказчика
  • Web Push: ui-push Playwright ✓; боевые VAPID на стенде заказчика — ops
  • Enterprise IdP: admin wizard + SCIM API готовы; live AD/SSO/Kerberos на контуре — ops
  • Мобильные клиенты iOS/Android — вне текущей поставки
  • Live-streaming L6 formal 10k soak — LSO-040 (Sep 2026+)

Что умеет продукт

Статус продукта ↑

Korus Messenger — корпоративный мессенджер для переписки, файлов, звонков и администрирования в контуре заказчика.

Девять блоков возможностей — в карточках ниже. Сводный статус и blockers — в шапке презентации.

Переписка и совместная работа

Реализовано

Личные и групповые чаты, вложения, ответы на сообщения, история переписки. Работает в браузере, можно закрепить ярлык «как приложение».

Поиск и файлы

Реализовано

Поиск по тексту сообщений и вложениям; превью изображений; скачивание файлов из чата. До ~50 тыс. рег. — SQL-поиск; выше — Solr.

Звонки из чата

Частично

Аудио/видео между участниками чата: mesh P2P и групповые конференции через LiveKit SFU. TURN для NAT/firewall в production настраивает IT заказчика.

Live-трансляции

Частично

Корпоративные эфиры: RTMP ingress, HLS-плеер, модерация и DVR в admin/API. Formal soak 10k зрителей — после появления stage (Sep 2026+).

Администрирование

Реализовано

Веб-консоль /admin/: организации, пользователи, аудит, ретенция; мастер auth-policy (LDAP/SSO), directory sync, live-сессии.

Комплаенс и архив

Реализовано

Экспорт переписки (JSON/ZIP), legal hold, dual-TTL ретенция, deep-archive.

Вход и безопасность

Частично

Login-options с экрана входа; auth-policy в /admin/ (LDAP, OIDC/SAML, Kerberos scaffold). SCIM 2.0 Users/Groups для провизионинга. E2EE (MLS) — после sign-off ИБ.

Боты и интеграции

Реализовано

Bot API с webhook outbox/retry, платформа плагинов L0–L3, мосты к 1С, почте, хранилищам.

Мобильные клиенты

Не в поставке

Нативные iOS/Android — вне текущей поставки; сценарии через браузер/PWA.

Зачем нужен

Корпоративный мессенджер — как привычный чат, но для работы: переписка с коллегами, файлы, звонок из чата.

Данные хранятся у вашей компании. Администратор может посмотреть переписку по правилам компании — для порядка и проверок.

Сейчас это рабочий прототип: основные сценарии уже можно попробовать на тестовом стенде.

Альтернативы

Есть облачные сервисы и решения «сервер у себя». Korus — когда важны контроль данных и выгрузка для аудита.

Отдельного приложения в App Store пока нет — достаточно браузера или «добавить на рабочий стол».

Удобство

Удобно: поиск по переписке, файлы в чате, звонок одной кнопкой.

Частично готово: уведомления на телефон настраивает IT; усиленное шифрование — после согласования с безопасностью.

Вопросы и сценарии

Девять типовых сценариев для онбординга сотрудников и блок частых вопросов — материал презентации, не экран справки в продукте.

Первый вход

  1. Откройте адрес, который выдал IT (браузер Chrome, Edge, Firefox)
  2. На экране входа выберите способ: пароль, LDAP или SSO — если включено
  3. После входа откроется список чатов вашей организации

Написать коллеге

  1. В списке чатов нажмите «Новый чат» → личная переписка
  2. Найдите коллегу по имени или выберите из списка
  3. Напишите сообщение и отправьте — Enter или кнопка отправки
  4. Статус «доставлено / прочитано» появится под сообщением

Групповой чат

  1. «Новый чат» → «Группа»
  2. Добавьте участников и задайте название (отдел, проект)
  3. Отправьте первое сообщение — все участники увидят историю с момента добавления
  4. Администратор может управлять составом по правилам компании

Отправить файл

  1. Откройте нужный чат
  2. Нажмите скрепку или перетащите файл в область сообщений
  3. Дождитесь индикатора загрузки
  4. Коллеги откроют превью или скачают файл из чата

Найти переписку или файл

  1. Откройте поиск (строка вверху списка чатов)
  2. Введите фразу, имя файла или имя отправителя
  3. Выберите результат — откроется нужное место в чате
  4. На больших внедрениях поиск может занять чуть дольше — это нормально

Ответить или процитировать

  1. Наведите на сообщение → «Ответить»
  2. Над полем ввода появится цитата исходного текста
  3. Напишите ответ — в группе будет видно, на что вы отвечаете

Звонок 1:1

  1. Откройте личный или групповой чат
  2. Нажмите иконку звонка (аудио или видео)
  3. Разрешите микрофон и камеру в браузере
  4. Завершите звонок той же кнопкой — запись разговора по умолчанию не ведётся

Групповая конференция

  1. В групповом чате начните звонок — подключатся участники чата
  2. Включите/выключите микрофон и камеру на панели звонка
  3. При большом числе участников IT может включить сервер конференций (SFU)
  4. Демонстрация экрана — если разрешено политикой браузера и организации

Ярлык «как приложение»

  1. Chrome / Edge: меню ⋮ → «Установить Korus Messenger» или «Приложения»
  2. Мессенджер откроется отдельным окном без вкладок браузера
  3. Push-уведомления на телефон настраивает IT — не из этого экрана

Частые вопросы

Чем не Telegram / WhatsApp?

Данные в контуре компании, политики хранения и выгрузка для аудита — не личный мессенджер на телефоне.

Нужно ли ставить приложение?

Достаточно браузера; ярлык на рабочий стол — по желанию. Отдельного клиента в App Store / Google Play пока нет.

Кто видит переписку?

Участники чата; администратор — по правилам организации и закону (как в корпоративной почте).

Можно ли удалить сообщение без следа?

Удаление в чате не отменяет обязанности хранения по политике компании — архив и экспорт для комплаенса настраивает IT.

Работает ли без интернета?

Нет — нужна сеть до сервера организации. При обрыве связи сообщения отправятся после восстановления.
